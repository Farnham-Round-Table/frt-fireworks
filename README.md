# Farnham Round Table

## Fireworks and Torchlit Procession Website

This is the repo for the Farnham Round Table fireworks event website. It's an [Astro](https://astro.build) static site: the page is built from simple markdown and data files in `src/content`, and deployed to Firebase Hosting.

**Editing the content?** Read [EDITING.md](EDITING.md). No coding needed.

```
npm install
npm run dev      # local preview
npm run build    # build into dist/
```
